### Overall decisions not yet accepted

Evidence supports **start with a single public-runtime package candidate**, ESM-first, strict exports and explicit CSS entrypoint **only after** consumer/peer/owner/legal review. Source registry blocks/templates is an **optional later** distribution channel (not a replacement for npm), and all package names and compatibility ranges are **proposals**. Documentation site, Skin Lab, Storybook, npm Trusted Publishing, Changesets, monorepo/workspace manager and CLI are **not selected/installed**. Formal reasoning: [ADR-0009](../adr/0009-package-topology.md), [ADR-0010](../adr/0010-package-distribution.md), [Package & DX Bible](../architecture/package-architecture-dx-bible.md).

## Decisions and open ADR

**Proposed:** WCAG 2.2 AA target, plus cautious reduced-motion, forced-colors, status not solely hue, and manual keyboard/AT review; a deterministic same-content **9 specimen × 30 appearance** baseline map with no fabricated captures; reuse *one* canonical 105-pair Skin Grammar matrix, no parallel pair records. CI static validity blockers active now; axe/browser screenshot tooling only after React consumer target #1 and package boundary #4.

**Open:** exact browsers/assistive-technology support matrix, Storybook+Playwright or narrower runner tradeoffs, version pinning, screenshot storage and git LFS/cost, snapshot diff tolerance only after reproducible sample, owner/waiver legal process, token contrast resolved values, RTL/locales. No code renderer or files have been produced.

**Normative vs informative:** WCAG SC define conformance criteria; W3C Understanding / APG / ACT Rules are guidance/techniques; vendor tools detect subsets and need manual evidence. Preserve this distinction in all release and defect summaries.

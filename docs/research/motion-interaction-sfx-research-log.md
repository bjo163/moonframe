### Conditional technology recommendation, not final selection

- **CSS-only** default candidate for simple state feedback/opacity/presence where DOM lifecycle can remove nodes semantically without waiting. Feature test first; prefer non-spatial static fallback.
- **Web Animations API** as browser-native optional internal tool if cancellation/orchestration actually needs it.
- **View Transitions** as opt-in route enhancement only if supported and focus/SSR/hydration tested; otherwise immediate navigation.
- **Motion for React** optional dependency only after a *measured* exit-presence/layout/gesture proof (focus safety, React peer versions, package size/license and reduced-motion parity); not installed here.
- **Audio:** avoid default engine in core. `HTMLAudioElement` for a few user-enabled cues, Web Audio for approved overlap/gain/mixing requirements, third-party e.g. Howler only after compatibility/license/size proof. No sound files generated.
- **Unresolved:** actual consumer browsers and SSR (#1), stable runtime package boundary (#4), primitive provider (#3), license, frame budget, timing/haptic measurements. No invented weights/bundle MB or latency benchmarks.

## Confidence and open ADR triggers

- **Source-derived:** React19 ref evolution, APG patterns, shadcn policy, provider-specific composition, WCAG criteria, test tool capabilities.
- **Architectural inference (proposed, not approved):** `onValueChange(next)` for non-native controlled selection, `onOpenChange(next,reason?)` for overlays, tab manual activation default, explicit compound parts for high-risk widgets, one public event per user intent.
- **Open:** React18 peer support, exact ref wrapper, provider choice, slot implementation (`asChild` versus `render`), SSR/direction/portal platform, public package paths and CSS merge utility. Compare fixtures, versions, licensing and exact support matrices before locking.

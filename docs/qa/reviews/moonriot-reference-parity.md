# Moonriot screenshot-based anti-clone review

This protocol checks whether Moonriot has a recognizable angular protest/editorial composition beyond a red accent applied to Moonpunk. It defines a future review; it does not report screenshots or a visual verdict.

## Capture setup

- Use the same deterministic content, component states, font availability, viewport, and browser for Moonriot and its comparator skins. Record the source commit and capture metadata with each image.
- Capture one desktop and one mobile viewport. Use the same fixed widths for every skin in a comparison set and record their CSS-pixel dimensions.
- For each viewport, capture color and grayscale views, each with optional decoration enabled and disabled. Do not replace missing consumer artwork with a fabricated reference image.
- Include a content-dense editorial view and a standard shared-component view so the comparison covers both Moonriot composition and common behavior.

## Comparison set and structural criteria

Compare Moonriot with Moonpunk and Moonsmash using identical content and states. The review should record observations for:

- Angular editorial grid, clipped or sharply divided regions, and asymmetric placement that remain identifiable in grayscale.
- Heading scale, line breaks, alignment, and spacing as structural choices rather than a color-only difference.
- Navigation and content grouping that communicate protest/editorial rhythm without relying on red alone.
- Decoration-off composition: semantic hierarchy and angular layout remain legible when optional art is removed.
- Mobile reflow: angular divisions simplify or stack without clipping, hiding content, or changing reading order.
- Shared controls retain the same labels, order, keyboard behavior, focus visibility, and state meanings in all compared skins.

## Evidence record

For each capture, record skin, mode, viewport, grayscale/decor state, source commit, and image SHA-256. A reviewer may then record concrete observations and a human judgment for each comparison. Keep missing captures, missing references, and unreviewed judgments explicitly pending; automated structure or file presence is not visual approval.
